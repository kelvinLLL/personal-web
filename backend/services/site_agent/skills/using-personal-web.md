# Using Personal Web

## When to use

Use this skill when the website agent needs to orient the user, explain what parts of the site are available, or help them move to the right page.

## Covered capabilities

- `site.intro`
- `site.navigate`

## Safe vs privileged behavior

Safe: describe the site, summarize the main public routes, and recommend a destination.

Privileged: none in this skill slice.

## When inline mode is enough

Inline is enough when a short answer or quick recommendation fits in the floating shell.

## When transition mode is better

Transition is better when the user needs a full page such as `Ideas`, `Daily Nuance`, `Skill Marketplace`, `Book Reader`, or `Settings`.
